## 🚀 Fluxo de Interação

### Demo 1 (Automação) - Mockado
```
Usuário vê:
  └─ Obrigações listadas (não editável)
  └─ Gatilho em R$ 300 (visual)
  └─ Split 80/20 configurado (visual)
```

### Demo 2 (Execução) - Interativo
```
Usuário clica:
  ├─ "Simula Pix R$ 150"
  │  └─ Pool atualiza → R$ 150.00
  │  └─ Timeline marca passos 1-2
  ├─ "+R$ 200 (atinge meta)"
  │  └─ Pool atualiza → R$ 350.00
  │  └─ Gatilho detecta meta atingida
  │  └─ Aluguel = R$ 300 (GREEN)
  │  └─ Uso = R$ 120 (CYAN)
  │  └─ Previdência = R$ 30 (AMBER)
  │  └─ Timeline marca todos os passos (✓)
  └─ "Zerar demo"
     └─ Retorna ao estado inicial
```

### Demo 3 (Impacto) - Inspiracional
```
Usuário lê (sem interação):
  └─ 4 cards de benefício
  └─ Callout final de impacto tangível
  └─ Copy emocional + prático
```
